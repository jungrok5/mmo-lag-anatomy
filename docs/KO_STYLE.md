# 한국어 문체 규칙

한국어 원문에서 번역투와 기계가 쓴 글에서 자주 보이는 표현을 걷어내는 규칙이다. `CLAUDE.md`의 문장 규칙(쉬운 말, 통용 용어, 증상 이름, 대시 금지, “A가 아니라 B” 금지)에 더해 쓴다. 검사는 `node tools/ko-style.cjs`가 한다.

규칙의 생각만 빌렸고 문장은 옮기지 않았다.

## 문체

- 본문 문장(장 설명, 원인의 `s`·`num`·`more`, 용어 정의 뒤 문장, 실험 안내)은 “~습니다/~입니다”.
- 개조식 칸(원인의 `c`·`act`·`chk`·`sig.g`, 출처 `n`, 표 칸)은 명사형이나 “~함/~봄”으로 끝낸다.
- 사례·절차(`cases.js`)의 서술은 “~다”.
- 한 문자열 안에서 “~다.”와 “~니다.”를 섞지 않는다. 굵은 머리말 문장도 뒤 문장과 같은 꼴로 쓴다.

## 쓰지 않는 표현

| 갈래 | 피할 꼴 | 바꾸는 방법 |
|---|---|---|
| 번역투 | ~에 있어(서), ~에 의해, ~와 관련하여, ~에 기반하여, ~을 가지고 있다, ~되어지다 | ~에서, 행위자를 주어로, ~에, ~로, 형용사·동사로, 단일 피동 |
| 번역투(문맥 판단) | ~에 대한/대해, ~을 통해, ~을 위해, ~에서의/~으로의, ~하게 된다, ~하고 있다, ~로 이어진다 | 목적격 조사, ~로, ~하려고·~하도록, 절로 풀기, 단순 동사, 단순 시제, 인과를 직접 |
| 분열문 | 문제는 ~입니다, 핵심은 ~입니다, 중요한 것은 ~ | 주어와 서술어를 바로 잇는다 |
| 형식명사 결말 | ~라는 점이 중요합니다, ~인 것입니다, ~라는 뜻입니다(잇따를 때) | ~습니다/~입니다로 끝낸다 |
| 상투어·메타 담화 | 결론적으로, 주목할 만하다, 중요한 역할, 앞서 설명했듯이, 살펴보겠습니다 | 지운다 |
| 수사·대구 | 반문으로 시작하는 문단, “반은 맞고 반은 틀립니다” 같은 대구, 슬로건 | 평서문으로 바로 말한다 |
| 직역 대명사 | 그것, 그들 | 가리키는 이름을 쓴다 |
| 덧붙임 | 문두 또한·따라서·즉·이는의 반복, “, 곧 ~” | 지우거나 앞 문장과 합친다 |
| 쉼표 | 연결어미 바로 뒤 쉼표(~하고, ~지만,) | 짧은 절이면 뺀다. 앞 절이 40자를 넘는 긴 문장만 남긴다 |
| 강조 | 정말로, 매우, 강조용 따옴표 남발 | 뺀다. 따옴표는 인용·메시지·용어 정의에만 |

## 지키는 것

- 사실, 수치, 단위, 버전, 고유명사, 명령어·지표 이름, 원인 ID, 자리표시자(`${…}`, `{0}`, `@@힌트`)
- 정보를 담은 완곡 표현(“~할 수 있습니다”, “대개”)과 당위(“~해야 합니다”)
- 이름 역할을 하는 글자: 원인 이름 `t`, 증상·층 이름, 용어 사전 표제어, 장·절 제목, 출처 제목. 다른 문장이 따옴표로 인용한다
- 통용 용어(`docs/TERMS.md`). 쉬운 말을 드문 한자어로 바꾸지 않는다

## 검사기

```bash
node tools/ko-style.cjs                  # 규칙별 건수
node tools/ko-style.cjs --show cleft     # 그 규칙에 걸린 문장과 자리
node tools/ko-style.cjs --strict         # '오류' 규칙이 하나라도 걸리면 실패(npm test에 포함)
```

- **오류**: 0건이어야 한다. 대시, “A가 아니라 B”, 이중 피동, “가지고 있다”, “~에 있어”, “~에 의해”, 경동사(“~을 수행한다”), 직역 대명사, 상투어, 분열문 “중요한 것은”, “~뿐만 아니라”, 완곡 겹침, 문체 섞임 등.
- **주의**: 정상 용례가 섞여 있어 문맥을 보고 고친다. “~에 대한”, “~을 통해”, “~하게 된다”, 연결어미 뒤 쉼표, 문두 접속사 등.
- 검사기는 사이트에 나오는 한국어 전부(`tools/i18n.cjs`가 뽑는 단위)를 본다. README와 docs는 보지 않는다.

한국어 문장을 고치면 번역은 빈 칸이 된다(`node tools/i18n.cjs sync`). 뜻을 바꾸지 않고 문체만 다듬었으면 옛 번역을 그대로 써도 되므로 `stale`에서 되살린다.

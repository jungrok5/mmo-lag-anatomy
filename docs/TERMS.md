# 표준 용어표 (렉 해부도감)

원칙: 비유나 멋 부린 말 대신 게임·서버·네트워크 현업에서 통용되는 말을 쓴다. 비전문가를 위해 처음 나올 때 괄호로 짧게 풀이한다. 풀이도 통용되는 말로 쓴다.

## 이미 일괄 교체함 (남은 것·어색해진 문장만 손본다)

| 전 | 후 |
|---|---|
| 손님 | 클라이언트 (서버 입장의 접속 상대). 사람을 가리키면 유저. 대기열 이론의 도착 대상은 요청. 같은 물리 서버의 다른 VM은 가상 머신 |

## 건드리지 않는 것

- 고정 증상 이름: 뚝뚝 끊김 · 순간이동 · 고무줄 · 몰아치기 · 슬로우모션 · 입력 지연 · 멈춤 · 씹힘·롤백 · 접속 끊김 · 접속 불가·무한 로딩 · 안 보임·유령 개체
- 게임 업계 통용어: 선입력, 선연출, 스킬 씹힘, 렉, 핑, 틱, 보간, 외삽, 예측, 되감기(지연 보상)
- 표준 한국어 기술 용어: 대기열, 지연, 손실, 재전송, 혼잡, 단편화, 스케줄링
- class="analogy"인 비유 상자 안의 비유 (상자 밖으로 새어 나온 비유어만 바꾼다)
- 숫자, 설정·카운터·API 이름, 버전, 조건, 기술 내용
